# 09 · 確認出場人物（追問前）

## 現況

- 路由：`GET/POST /events/{id}/cast`  
- 模板：`ui/templates/cast.html`  
- 時機：建立／後續存 draft **之後**、**AI 追問之前**

## 規格鎖定

| 項目 | 決議 |
|------|------|
| 目的 | 避免職稱／泛稱被當人名（例：主管→小主管） |
| 可操作 | 改名、標「是我本人」、刪除、新增 |
| 疑似職稱 | `LIKELY_ROLE_LABELS` 高亮提示（主管、老闆、同事…） |
| 完成標記 | `notes` 含 `cast_ok=1` |
| 舊草稿 | 已有 qa／成稿者不強制回退 |

## 流程

```text
主文 → AI 初稿 → 確認出場 → AI 追問 → … → 成稿 → 評分落盤
```
