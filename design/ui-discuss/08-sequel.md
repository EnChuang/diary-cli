## 規格鎖定

### 使用者確認（後續鏈）

| # | 決策 |
|---|------|
| 1 | **一父多子** |
| 2 | 僅**已可閱讀**（confirmed + 成稿）可按「後續 +」 |
| 3 | AI 回憶：父成稿 + 問答 + 當次分；正文＝**銜接 + 新內容**（不重印父全文） |
| 4 | **再評一輪**；可反轉；AI 估力道；可調分；本場 ±10 |
| 5 | 子：D21 + **只回父**；父：可**選各子**（含未完成草稿見下） |
| 6 | 標題參考父題 + **`續・`** 前綴 |
| 7 | **禁止刪父留子** |
| 8 | 用詞：**後續** |

### 草稿策略（D24｜防混亂）

| 項 | 決策 |
|----|------|
| 可否存草稿 | **可以**（新建與後續皆可中途持久化） |
| **草稿數量** | **全庫最多 1 份**未 confirmed 草稿（防多篇半成品混亂） |
| 再開寫 | 點**新增**或**後續 +** 時若已有草稿 → 詢問框： |
| 詢問框 | **① 繼續寫** → 進入該唯一草稿；**② 放棄後開新的** → 刪草稿再開本次流程 |
| 觸發 | **僅**「新增」「後續 +」時若有草稿才問 |
| 冷啟動 | **不彈**草稿詢問（可直接進首頁；草稿仍在庫，點新增／後續才問） |
| 何謂草稿 | 未 `confirmed`（含 draft／awaiting_generate／已成稿未落盤） |
| 父篇子列表 | 若唯一草稿的 parent 是此父，可顯示並標「草稿」 |
| 第一版範圍 | **先 Web**；CLI 後續可後補 |
| 刪已落成 | **第一版不做**；僅「放棄草稿」可刪未 confirmed |

### 實作預設（邏輯審查｜已定）

| 點 | 預設 |
|----|------|
| 子篇 body | 銜接 + 新發展 only |
| 評分對象 | 只評**本則**有出場／語氣者 |
| 導覽 | 子→直接父；父→子列表 |
| 標題 | `續・` + 短題；手填缺前綴則補上 |
| 回憶包 | 讀父當下資料，不存死快照 |
| 落盤 | 後續 confirmed 時寫 ledger；草稿不寫 ledger |
| 繼續草稿落地頁 | 依 status：draft→追問（必要時先補初稿）；awaiting_generate→成稿；有 story 未 confirm→評分 |
| 列表 | 未 confirmed 標 badge「草稿」；榜不顯示未落盤分 |

## 可行性（結論：**可行**）

| 面向 | 說明 |
|------|------|
| 與現況 | CLI／Web **已在**中途寫 draft，比「不存」更貼現碼 |
| 詢問框 | 前端狀態機 + 查「未 confirmed 且（可選 parent 條件）」即可 |
| 後續草稿 | 一開始就可建 `event`（status=draft, parent_event_id=父），與新建一致 |
| 放棄草稿 | 刪該 event 列（若無 ledger）；**不得**刪已有子篇之父 |
| 單草稿 | 新建或開後續前若已有草稿 → 必須先繼續或放棄，無法再開第二份 |
